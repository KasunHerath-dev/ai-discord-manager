Set up the FasNet V2 Discord server as a professional project collaboration workspace.

Do not delete the server, modify the server owner, remove existing members, invite users, publish invitation links, or change unrelated settings.

Create these category and channel groups:

1. INFORMATION
- welcome
- announcements
- project-vision
- rules-and-workflow
- team-directory

2. PRODUCT AND REQUIREMENTS
- requirements
- feature-ideas
- user-research
- decisions
- meeting-notes

3. UI-UX
- ui-ux-general
- user-flows
- wireframes
- figma-updates
- design-reviews

4. DEVELOPMENT
- architecture
- frontend
- backend
- database
- api-discussions
- dev-help

5. QUALITY AND RELEASE
- qa-testing
- bug-reports
- code-reviews
- integration
- release-updates

6. TEAM VOICE CHANNELS
- Core Team Meeting
- UI-UX Meeting
- Development Meeting
- General Work Room

Create these roles:
- Project Lead
- Product Team
- Technical Lead
- UI-UX Team
- Front-end Team
- Back-end Team
- QA Team
- Core Team
- Member
- Guest

Permissions:
- Only Project Lead and Technical Lead can manage server-wide settings.
- Only authorized leads can post in announcements.
- Guests can see welcome, announcements, project-vision, and rules-and-workflow only.
- Private core-team discussions are visible only to Project Lead, Technical Lead, and Core Team.
- Development channels are accessible to relevant development roles.
- Do not grant Administrator automatically. Flag it as a blocked request if requested.

Add a clear topic to every text channel.
Post a welcome message explaining that FasNet V2 is a centralized digital campus ecosystem connecting students with academic information, societies, events, opportunities, and university services.

Post rules covering:
- Respectful communication
- No sensitive credentials in chat
- Decisions must be documented
- Tasks must have owners and deadlines
- Development work must use GitHub issues and pull requests
- Requirements must be approved before implementation
- Designs must be reviewed before development
- Bugs must include reproduction steps

Present all permission changes for approval. After completion, report categories, channels, roles, permission rules, and manual actions.

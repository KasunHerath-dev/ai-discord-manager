# Antigravity instructions

This repository is a local Discord administration control plane.

- Never request, print, log, copy, commit, or expose Gemini or Discord credentials.
- Use the browser first-run wizard for all secrets.
- Never bypass plan validation, approval, typed confirmation, or snapshots.
- Never add automatic `Administrator` assignment.
- Preserve unrelated roles, channels, permissions, members, and messages.
- Run `npm run check` and `npm test` after every code change.
- Use `templates/FASNET_V2_SETUP_PROMPT.md` for the first server setup.
